# 風語輸入法

AIW 風光Ai窗 注音輸入法。

## 特色

- 中英混打：不用切換，直接打英文或注音，系統自動判斷
- 組字直接顯示中文，候選框預設隱藏，按 ↓ 叫出
- 收錄教育部《重編國語辭典修訂本》所有字詞讀音，並保留舊讀音與習慣讀音
- 「一」「不」照實際讀音打也能出字（ㄧˊ ㄧㄤˋ → 一樣）
- 手快打反注音順序也能正確出字

## 使用方式

| 動作 | 按鍵 |
| :--- | :--- |
| 叫出候選字 | ↓ |
| 送出整句 | Enter |
| 英文單字後送出並空一格 | 空白鍵 |
| 英文照原樣送出 | Enter |
| 一聲 | 空白鍵 |
